## 🚀 Key Features

- **⚡ AI-Accelerated Systems Engineering**: Differentiating from fragile AI vibe-coding through battle-tested multi-platform systems architecture.
- **🎮 Live 3D Graphics Viewport (KozEngine)**: Built-in 60 FPS interactive spatial mesh engine running directly in WebGL with wireframe/solid shading toggles and telemetry HUD.
- **💼 Production Case Studies Showcase**:
  - **[SmartRename AI](https://smartrenameai.online)**: Autonomous computer vision & asset classification engine.
  - **[Zinter](https://zinter.com.ng)**: Enterprise omnichannel digital connectivity & operations platform.
  - **KozEngine (Nexus 3D)**: Proprietary cross-platform 3D game engine for Web, Mobile, and PC.
  - **NexaFi**: AI-Powered DeFi Neobank and cross-border financial rail.
  - **VaultStream EDMS**: Enterprise Electronic Document Management System with encrypted vaults.
  - **Nuvral**: B2B customer acquisition and pipeline automation engine.
- **📊 Interactive Scope & Budget Calculator**: Instant multi-step engineering estimator calculating sprints, timeline, and investment.
- **📝 Technical Blog & Creator Studio**: Full blog system with Markdown file drag-and-drop upload, live preview, search, category filters, and local persistence.
- **⚡ Rapid Micro-Services**: High-velocity fixed-scope engagements (AI Code Audits, 48h Performance Tuning, Electron Desktop Packaging, 3D WebGL Heroes).
- **📬 Inquiries Routing**: Submissions routed directly to `info@kozmaktechnologies.com`.
- **🔍 Comprehensive Technical SEO**: Schema.org JSON-LD structured data (`Organization`, `Service`, `FAQPage`), OpenGraph preview cards, and sub-second load times.

## 💻 Local Development

```bash
# Clone repository
git clone https://github.com/Kozy04/kozmaktechnologies.git

# Navigate into project
cd kozmaktechnologies

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
